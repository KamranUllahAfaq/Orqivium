# Governance examples

- `safe-readonly-workflow.json` is a minimal retrieval-to-answer graph and passes `standard` policy.
- `high-risk-action-workflow.json` accepts webhook input, retrieves untrusted content, and reaches a mutating HTTP action without approval. It is blocked by `high_assurance` policy.
- The adjacent audit files were generated by `scripts/orqivium_workflow_audit.py`.

Reproduce:

```bash
python scripts/orqivium_workflow_audit.py \
  examples/governance/high-risk-action-workflow.json \
  --mode high_assurance \
  --format json
```
